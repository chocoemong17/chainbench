# Reports

`chainbench report --format markdown|csv|json` runs the entire registered suite. Use `--output path` to write a UTF-8 file. Existing files are protected unless `--force` is supplied; missing parent directories are reported as errors rather than created implicitly.

`CONSISTENT` means the finite quantitative condition passed. `NOT CONSISTENT` means it failed. `INFO` has no quantitative pass/fail threshold and is allowed in a successful run. See [SOURCE_MAP.md](SOURCE_MAP.md) for the distinction between a theoretical bound, the heavy-ball empirical tail condition and the ISTA/FISTA observation.

Example:

```bash
chainbench report --format markdown --output report.md
chainbench report --format csv --output report.csv
chainbench report --format json --output report.json
```

JSON rejects non-finite values rather than emitting non-standard NaN/Infinity tokens. CSV uses standard quoted cells. Markdown escapes vertical bars in metrics. Reports contain no telemetry or timestamps. The committed benchmark snapshot is generated by the package; it is not external validation. Tests compare numeric snapshot cells with rtol=1e-6 / atol=1e-12, while labels and statuses must match exactly.
