# 피드백 → 변경 → 확인한 근거

[English](FEEDBACK_ACTIONS.md) · [수업 활용 기록과 전체 집계](CLASSROOM_PILOT.ko.md)

실제 반영한 변경과 아직 제안 단계인 작업을 구분합니다. 원본 엑셀과 학생별
응답은 비공개로 유지하며, 이번 작업에서 새로운 응답이나 추천을 수집하지 않았습니다.

| 근거 | 대응 | 진행 상태·확인 | 아직 모르는 것 |
| --- | --- | --- | --- |
| 제공된 150명 응답 중 60명이 더 직접 다루고 싶다고 응답 | Attention·ResNet에 예상→조작→관찰 활동, 학생 중심 30분 진행안 추가 | [PR95](https://github.com/chocoemong17/chainbench/pull/95) 반영·한영 브라우저 검사 | 개선 뒤 흥미나 이해가 얼마나 달라졌는지 |
| 운영자가 전달한 교사의 내용 준비 부담 | 핵심 문장·관찰 결과·오해하기 쉬운 점을 담은 안내 | [교사용 안내](TEACHING_GUIDE.ko.md) 세 편 작성 완료 | 다른 교사의 독립적 활용, 실제 준비 시간 |
| 54명이 다른 주제를 원함, 85명이 잘 모르겠다고 응답 | 기존 주제와 연결되는 세 편의 시안 제안 | 이번 검토 단계, 추가 학생 평가 없음 | 어떤 주제가 재방문으로 이어지는지; 유보 응답을 부정으로 해석하지 않음 |
| 이전 설명이 너무 쉽다가 어려워졌고, 후속 버전을 약5 수준으로 승인 | 한 가지 원리·필요한 만큼의 장면·짧은 문장·접힌 계산 설명 | 새 기획서에 적용, 이번 난이도 승인은 대기 | 이번 시안도 적절한지 |
| 먼저 시안을 검사받고 정교화하라는 명시적 요청 | 논문별 별도 승인, 시안은 검토 브랜치에서 공유 | [검토 문서](reviews/learning-foundations/README.ko.md), [기획 양식](templates/LESSON_BRIEF.md) | 새 시안에 대한 사용자 판단 |

운영자 설명에 따르면 1·5회차는 진행자 중심, 2~4회차는 학생 중심이었습니다.
응답의 체험 방식은 진행자 시연 60명·친구 화면 관찰 30명·직접 조작 60명으로
별도 집계됩니다. 무작위 비교가 아니고 행별 회차 대응도 제공되지 않았으므로,
회차별 통계나 직접 조작의 인과 효과를 만들지 않습니다. 교사 의견은 운영자가
전달한 의견이며 독립적 도입 실적이 아닙니다. 이해도는 응답자가 느낀 이해도입니다.

후속 작업에도 실제 의견·변경 링크·확인 결과만 추가합니다. 새 수업의 교육 효과는
검증되지 않았습니다. 시안을 승인받고 제작·검사를 마쳐 공개하기 전까지 완성
수업의 수는 세 편으로 유지합니다.

## 2026-10-05 시안 재검토

사용자가 1차 시안이 너무 단순하다고 지적했습니다. 역전파는 다섯 변수의 AB+CDE와 분기별 역방향 계산, CNN은 필터 이동·출력 채우기·다층 입체 구조·행렬 비교, Dropout은 여러 중간층의 참여 조합으로 확장했습니다. 네 장면 제한을 없앴습니다. [수정 시안](reviews/learning-foundations/README.ko.md)은 다시 승인 대기이며 학생 재평가나 정확도 향상 근거로 집계하지 않습니다.
