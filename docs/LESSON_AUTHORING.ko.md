# 시각화 수업 추가하기 — 시안을 먼저 검토합니다

[English](LESSON_AUTHORING.md) · [복사할 기획 양식](templates/LESSON_BRIEF.md)

현재 완성된 수업은 **Adam·Attention·ResNet 세 편**입니다. 역전파·CNN·Dropout은
`study/learning-foundations` 브랜치의 **승인 전 시안**이며 완성 편수에 포함하지 않습니다.

1. 양식을 `docs/reviews/<주제>/BRIEF.md`로 복사합니다. 원문과 정확한 절을 적고,
   한 가지 특징이 눈에 드러나는 예시를 고릅니다. 모든 방법을 좌표 그래프로 설명할 필요는 없습니다.
2. 바꿀 값·고정할 값·표시할 숫자·예시의 한계를 적습니다. 별도 계산으로 숫자를
   검증합니다. 이번 예제는 기울기를 유한차분으로 비교하고 Dropout의 16개 조합을 모두 계산합니다.
3. 네 장면을 간단한 그림과 한 문장으로 만듭니다. 영어 기본·한국어 선택,
   움직이는 시안과 천천히 읽을 정지 그림을 함께 제공합니다.
   [이번에 채운 기획서](reviews/learning-foundations/BRIEF.md)를 참고하세요.
4. GitHub Actions에서 계산·글자·이미지 검사를 하고 각 장면을 직접 확인합니다.
   GitHub의 검토 문서 링크로 공유하면 ZIP이나 Python 설치가 필요 없습니다.
   실제 검토한 버전과 의견을 기록하고 **설명 방식·난이도를 승인받습니다**.
5. 승인받은 뒤 영상·두 개의 조작 그래프·원문 연결을 정교화합니다. 기존
   `web/papers/shared/lesson.js`, `scripts/render_visual_papers.py`,
   `scripts/check_visual_papers_browser.py`가 구현·검사의 참고 예입니다.
6. PR과 필수 CI, main 검증을 거쳐 기존 `pages.yml`로 공개합니다.
   시안 브랜치의 이미지를 공개 사이트의 완성 수업으로 배포하지 않습니다.

렌더링은 클라우드에서 하며 검토 이미지 묶음은 5 MB 이내로 제한합니다.
로컬에는 작은 소스만 편집하고 공용 도구를 재사용합니다.
학생별 응답·종전 비공개 문서·논문 PDF를 추가하지 않습니다.

[피드백과 개선 기록](FEEDBACK_ACTIONS.ko.md)에는 의견의 출처, 실제 반영한 변경,
미검증 부분을 구분합니다. 개선 뒤 학생 반응을 다시 받지 않았다면 효과가
검증되었다고 적지 않습니다. 수치 검사의 통과도 사용자의 설명 승인과 다릅니다.
