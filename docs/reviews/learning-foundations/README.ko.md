# 수정 시안 3차 — 갈라지는 계산·움직이는 필터·여러 층

[English](README.md)

이번 의견을 반영해 **반복 갱신·CNN 숫자 표시·Dropout 노드 축소**를 추가했습니다. 역전파는 12단계, CNN은 9개 설명 장면과 82개 필터 위치, Dropout은 8개 설명 장면으로 구성했습니다. 움직이는 그림을 바로 보고, 아래 정지 그림을 펼쳐 천천히 읽을 수 있습니다. **설명 방식·난이도 재검토용이며, 완성 영상 제작 전입니다.**

## 1. 역전파: AB + CDE

다섯 변수 A·B·C·D·E에서 출발해 AB+CDE를 계산합니다. 오차의 변화 신호를 더하기에서 두 갈래로 보내고, 곱셈마다 상대편 값을 곱해 다섯 기울기를 구합니다. 첫 번째 갱신은 자세히 보고, 두 번째부터는 순방향 → 역전파 → 갱신을 빠르게 반복합니다. **총 6번 갱신하며 목표 4에 가까워지는 모습**을 마지막 그래프에 모았습니다.

## 2. CNN: 움직이는 필터와 여러 층

3×3 필터가 한 칸씩 움직이며 출력 칸을 채웁니다. **입력의 색칠된 칸에는 1을, 계산된 출력 칸에는 실제 값을 표시**하고, 0은 빈칸으로 둡니다. 다른 필터, 두 칸씩 가는 스트라이드, 채널을 쌓은 입체 구조, 다음 층의 결합과 출력까지 이어집니다. 끝에서는 CNN과 같은 계산을 큰 행렬 곱으로 펼친 뒤 파라미터를 비교합니다. **비교는 첫 층의 구조이며, 같은 정확도를 냈다는 성능 실험이 아닙니다.**

## 3. Dropout: 3 → 5 → 5 → 2
