# 수정 시안 2차 — 갈라지는 계산·움직이는 필터·여러 층

[English](README.md)

요청하신 내용을 반영해 **네 장면 제한을 없앴습니다.** 역전파는 10단계, CNN은 9개 설명 장면과 82개 필터 위치, Dropout은 8개 설명 장면으로 구성했습니다. 움직이는 그림을 바로 보고, 아래 정지 그림을 펼쳐 천천히 읽을 수 있습니다. **설명 방식·난이도 재검토용이며, 완성 영상 제작 전입니다.**

## 2. CNN: 움직이는 필터와 여러 층

3×3 필터가 한 칸씩 움직이며 출력 칸을 채웁니다. 다른 필터, 두 칸씩 가는 스트라이드, 채널을 쌓은 입체 구조, 다음 층의 결합과 출력까지 이어집니다. 끝에서는 CNN과 같은 계산을 큰 행렬 곱으로 펼친 뒤 파라미터를 비교합니다. **비교는 첫 층의 구조이며, 같은 정확도를 냈다는 성능 실험이 아닙니다.**

## 3. Dropout: 5 → 10 → 5 → 2

## 이번 검토에서 확인할 점

역전파는 분기마다 계산이 이어지는지, CNN은 필터의 이동·여러 층·행렬 비교가 보이는지, Dropout은 여러 층에서 조합이 바뀌는 이유가 전달되는지 봐 주세요. 각 주제별로 **적당함 / 설명 수정 / 난이도 조절** 의견을 주시면 됩니다. 승인된 주제만 정교화합니다.
