# 중학생 수업 5회 활용 기록

[English](CLASSROOM_PILOT.md) · [교사용 안내](TEACHING_GUIDE.ko.md) ·
[웹에서 체험하기](https://chocoemong17.github.io/chainbench/papers/?lang=ko)

프로젝트 운영자는 중학생 수업 5회에서 시각화 자료를 사용했다고 설명하고,
익명으로 정리한 150명의 10문항 응답 기록을 제공했습니다.
수업 후 느낀 이해도·흥미·선호를 조사한 비공식 활용 사례입니다.
정답을 확인한 이해도 시험이나 학습 향상 측정은 아닙니다.

이 설문은 당시 보여 준 이전 자료에 관한 것입니다. 이후 정교화해 추가한
역전파·CNN·Dropout 세 편을 평가한 결과로 사용하지 않습니다.
[짧은 프로젝트 소개](https://chocoemong17.github.io/chainbench/about/?lang=ko)에서
현재 여섯 콘텐츠와 이 수업 기록을 함께 살펴볼 수 있습니다.

## 수업 운영 방식

운영자 설명에 따르면 **1·5회차는 진행자 중심, 2~4회차는 학생 중심 활동**이었습니다.
학생 중심 활동에는 친구가 조작하는 화면을 보는 경우도 포함됩니다.
응답 파일에는 진행자 화면 시청 60명, 친구 화면 시청 30명, 혼자 직접 조작 60명이 기록되어 있습니다.

운영자는 다른 교사·강사에게 내용을 소개했을 때 활용할 만하다는 의견을 들었고,
교사가 내용을 먼저 이해하는 준비 시간이 필요했으며 이후 학생들이 설명을 이해하는 것을
확인했다고 전했습니다. 이는 운영자가 전달한 현장 의견입니다.
독립적으로 기록된 외부 교사의 수업 사례, 직접 인용문 또는 추가 설문 응답자로 집계하지 않습니다.

파일에는 수업 날짜, 회차별 논문, 전체 참석 인원, 별도 회차 열이 없습니다.
행을 임의로 30개씩 나누어 회차별 통계나 응답률, 수업 방식의 효과를 계산하지 않았습니다.

## 응답 결과

문항 번호는 이번 수업을 위해 제시한 최종 10문항 설문과 연결했습니다.
원본 엑셀에는 설문 전문 대신 문항 번호와 응답 번호가 있습니다.
[집계 기록](data/classroom-survey-150.json)에 한국어 질문·선택지와 0명을 포함한 모든 빈도를 담았습니다.

| 문항과 집계 기준 | 응답 수 | 150명 중 비율 |
| --- | ---: | ---: |
| 1번: 처음 듣는 내용이었다 | 146명 | 97.3% |
| 2번: 대부분 또는 거의 다 이해했다고 느꼈다 | 139명 | 92.7% |
| 3번: 조금 또는 매우 어려웠다 | 19명 | 12.7% |
| 4번: 조금 또는 매우 재미있었다 | 73명 | 48.7% |
| 4번: 재미는 보통이었다 | 39명 | 26.0% |
| 4번: 별로 또는 전혀 재미없었다 | 38명 | 25.3% |
| 5번: 영상의 움직임을 알아보기 조금 또는 매우 쉬웠다 | 141명 | 94.0% |
| 9번: 다른 주제도 조금 또는 매우 배우고 싶다 | 54명 | 36.0% |
| 9번: 다른 주제 학습 의향은 아직 모르겠다 | 85명 | 56.7% |
| 9번: 다른 주제를 별로 또는 전혀 배우고 싶지 않다 | 11명 | 7.3% |
| 10번: 직접 조작하는 시간을 늘리고 싶다 | 60명 | 40.0% |
| 10번: 지금 정도가 좋다 | 90명 | 60.0% |

가장 재미있었던 부분은 그래프 값에 따른 결과 변화 73명, 생활 속 예시 55명,
움직이는 영상 22명이었습니다. 하나를 고른 선호이며 각 요소의 품질 점수는 아닙니다.

진행자 화면을 봤다는 60명 전원이 직접 조작 시간 확대를 선택했습니다.
이는 수업 방식이 달랐다는 운영자 설명과 일치하는 양상입니다.
다만 재미의 긍정 응답은 진행자 화면 시청 30/60명, 친구 화면 시청 17/30명,
혼자 조작 26/60명이어서 직접 조작의 효과를 단정할 수 없습니다.
집단을 무작위로 배정한 비교가 아니며 수업 조건·집단 차이가 남아 있습니다.

## 피드백을 반영한 변경

- Attention·ResNet의 기존 그래프 옆에 **예상하기 → 움직이기 → 살펴보기** 활동을
  접힌 안내로 추가했습니다. 점수를 매기거나 응답을 수집하지 않습니다.
- 세 편 각각에 핵심 한 문장, 조작 순서, 관찰할 결과, 흔한 오해를 담은 교사용 안내를 마련했습니다.
- 학생이 번갈아 직접 조작하고 생활 속 쓰임을 연결하는 30분 수업 진행안을 넣었습니다.

기존 영상과 계산 예시·해석 범위는 유지했습니다.
이번 변경은 피드백에 대응한 개선이며 개선 후 효과는 아직 조사하지 않았습니다.

## 자료의 범위

학생 표기는 150개로 서로 다르고, 1,500개 응답에 빈칸이나 1~5 범위 오류가 없습니다.
같은 답변 조합만으로 동일인을 판단할 수 없어 해당 행도 모두 유지했습니다.
파일은 운영자가 전달했으며 입력 검사는 실제 참여자와 조사 환경의 독립 검증이 아닙니다.

1번은 과거 친숙도를 돌아본 응답, 2번은 수업 후 이해도 자기평가입니다.
두 값을 빼서 학습 향상을 계산하지 않았으며 선택 번호를 합산한 총점도 만들지 않았습니다.
이 조사만으로 사이트 단독 학습, 장기 기억, 재방문이나 전체 중학생에 대한 효과를 주장하지 않습니다.

공개 자료에는 집계만 담았습니다. 학생별 원본 엑셀·학생 표기·비공개 대화는 저장소에 포함하지 않습니다.
집계로 비율 계산은 재확인할 수 있으나 응답 수집 과정까지 독립 확인할 수 있는 것은 아닙니다.
