Optional: the numbers, assumptions and sources자세히 보고 싶다면: 계산·조건·출처

Constructed expression y = AB + CDE, target 4, loss L = (y − 4)² / 2. Initial A…E = [2, 3, 2, −1, 2]. All five variables update simultaneously with gradient descent at rate 0.02. Addition passes the incoming derivative to both branches; multiplication uses the other factor. This finite example improves at all six shown steps. Other step sizes can increase loss. This is a chain-rule illustration, not the paper’s sigmoid experiment.

직접 정한 식 y = AB + CDE, 목표 4, 오차 L = (y − 4)² / 2입니다. 초기 A…E는 [2, 3, 2, −1, 2]이며 보폭 계수 0.02의 경사하강으로 동시에 갱신합니다. 더하기는 두 입력에 변화 신호를 각각 전달하고, 곱하기는 상대편 값을 곱합니다. 표시된 여섯 단계는 모두 개선되지만 다른 보폭에서는 오차가 커질 수 있습니다. 연쇄법칙 설명용이며 원문의 sigmoid 실험은 아닙니다.
