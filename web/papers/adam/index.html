What exactly are we watching?어떤 조건으로 만든 영상인가요?

An unequal-scale quartic: f(x,y) = φ(x) + 10,000 φ(y), φ(z) = z²/2 + z⁴/4. All methods start at (−3, 2) and take 1,200 full-gradient updates; the minimum is (0, 0). GD uses α = 3.9810717055349695 × 10⁻⁵; Momentum uses α = 2.2067340690845897 × 10⁻⁵, β = .985935; Adam uses α = .14, β₁ = .9, β₂ = .999, ε = 10⁻⁸, with both bias corrections. Baselines were tuned on this example; these are finite-grid choices, not globally optimal settings.

방향별 경사 차이가 큰 4차 함수입니다. f(x,y) = φ(x) + 10,000 φ(y), φ(z) = z²/2 + z⁴/4. 같은 점 (−3, 2)에서 전체 기울기로 1,200번 갱신하며 최소점은 (0, 0)입니다. GD는 α = 3.9810717055349695 × 10⁻⁵, Momentum은 α = 2.2067340690845897 × 10⁻⁵·β = .985935, Adam은 α = .14·β₁ = .9·β₂ = .999·ε = 10⁻⁸이며 두 편향 보정을 적용합니다. 다른 방법도 이 예시에서 조율했으며, 유한한 탐색 결과로 전역 최적 설정을 뜻하지는 않습니다.

The target requires distance ≤ 1% and objective ≤ 0.01% of their initial values, maintained through update 1,200. Equal gradient calls, not wall-clock speed. Adam follows the paper's Algorithm 1; this constructed scene is separate from its neural-network experiments. Surface height is log(1 + objective); the front wall is shown as a wireframe so the floor stays visible. All plotted states are computed iterates.

목표 구간은 초기 거리의 1%·초기 함수값의 0.01% 이하이며, 1,200회까지 유지했는지 확인합니다. 실행 시간이 아닌 같은 기울기 계산 횟수의 비교입니다. Adam은 원 논문의 알고리즘 1을 따르며, 논문의 신경망 실험과는 별도의 예시입니다. 높이는 log(1 + 목적함숫값)이고, 앞쪽 벽을 와이어프레임으로 표시해 바닥까지 볼 수 있습니다. 모든 경로는 실제 계산한 반복점입니다.
