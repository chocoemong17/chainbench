What exactly are we watching?어떤 조건으로 만든 영상인가요?

A constructed Rosenbrock valley, rotated 30°. All methods begin at the same point and receive 2,400 full-gradient updates. GD uses α = .001; classical momentum uses α = .001, β = .9; Adam uses α = .02, β₁ = .9, β₂ = .999, ε = 10⁻⁸, with bias correction. These are fixed illustrative choices, not tuned optima or the paper's recommended learning rate.

30° 회전시킨 Rosenbrock 골짜기입니다. 같은 점에서 시작해 전체 기울기로 각각 2,400번 갱신합니다. GD는 α = .001, Momentum은 α = .001·β = .9, Adam은 α = .02·β₁ = .9·β₂ = .999·ε = 10⁻⁸이며 편향 보정을 적용합니다. 예시를 위한 고정 설정으로, 최적 조율 결과나 논문이 권장한 학습률은 아닙니다.

Adam follows Algorithm 1 of the paper. This deterministic scene is an added explanation, not a reproduction of its neural-network experiments. Surface height is log(1 + objective); the two charts use the original numbers. Lines connect computed steps. No optimizer states are interpolated.

Adam 갱신은 원 논문의 알고리즘 1을 따릅니다. 이 결정론적 장면은 설명을 위해 추가한 것으로 논문의 신경망 실험을 재현한 것이 아닙니다. 표면의 높이는 log(1 + 목적함숫값)이며, 두 그래프는 원래 수치를 사용합니다. 선은 실제 계산한 반복점을 잇습니다.
