Dropout is used during training to discourage excessive co-adaptation. Here, fixed weights isolate the masking mechanism so you can see exactly what changes.Dropout은 학습 중 특정 노드끼리만 지나치게 맞춰지는 것을 줄이려는 방법입니다. 여기서는 가중치를 고정해 참여 조합이 바꾸는 것을 살펴봅니다.

Optional: the numbers, assumptions and sources자세히 보고 싶다면: 계산·조건·출처

A 3→5→5→2 network with two ReLU hidden layers, fixed signed weights and zero biases. Five Bernoulli(0.5) masks use seed 23; inputs and outputs are never dropped. Node labels are indices, not activation values. This uses the paper’s unscaled training / test-time weight scaling convention: keep W1 and multiply W2 and W3 by 0.5 for prediction. It is not inverted dropout and does not claim exact equality with a nonlinear ensemble average. These are computed scores, not class probabilities, a training run or a measured generalization gain.

중간층에 ReLU를 쓰는 3→5→5→2 구조이며 고정 가중치와 0인 편향을 사용합니다. 시드 23으로 만든 다섯 참여 조합은 각 중간 노드를 확률 0.5로 남깁니다. 입력과 출력은 제외하지 않으며 노드 숫자는 계산값이 아닌 번호입니다. 원문의 학습 시 비조정·예측 시 가중치 조정 방식을 사용합니다. W1은 유지하고 W2·W3을 각각 0.5배 합니다. Inverted dropout이 아니며 비선형 앙상블 평균과 정확히 같다는 주장도 아닙니다. 점수는 계산값이며 확률·실제 학습·일반화 성능 측정 결과는 아닙니다.
