The residual is the correction to useful features. If nothing needs changing, it can be zero.잔차는 쓸 만한 정보에 보탤 수정분입니다. 바꿀 필요가 없다면 0이면 됩니다.

The shortcut carries 2.0; the branch adds 0.1. The prediction 2.1 is close to the target 2.2.지름길이 2.0을 전하고 가지가 0.1을 더합니다. 예측 2.1과 정답 2.2 사이에 차이가 남습니다.

Backpropagation calculates how changes affect error. The branch and shortcut both send signals back; an optimizer uses them to update weights.역전파는 값의 변화가 오차에 미치는 영향을 계산합니다. 가지와 지름길 모두 신호를 돌려보내며, 최적화 알고리즘이 이를 사용해 가중치를 바꿉니다.

Residual connections let layers refine useful features and give gradients another route backward. These two ideas make deep networks easier to optimize in many settings.잔차 연결은 쓸 만한 정보를 다듬도록 하고, 기울기가 돌아가는 경로를 더합니다. 이 두 원리는 깊은 신경망을 학습하기 쉽게 만드는 데 도움이 됩니다.

The feature-grid scene is a separate illustration of a learning target: add two cells and remove one. The scalar block uses F(x) = a[−0.1 ReLU(x) + 0.3], x = 2, target = 2.2, loss = (y − target)² / 2. Dragging a from 0 to 1 changes chosen weights; it is not a training run. At a = 1, F = 0.1, y = 2.1. The incoming gradient is −0.1, the shortcut contributes −0.1, and the branch contributes +0.01; their sum is −0.09. The branch weight gradient is −0.2. Backprop computes derivatives; an optimizer performs the update.

격자 장면은 2칸을 더하고 1칸을 지우는 학습 목표의 별도 그림입니다. 숫자 블록은 F(x) = a[−0.1 ReLU(x) + 0.3], x = 2, 정답 = 2.2, 손실 = (y − 정답)² / 2를 사용합니다. a를 0부터 1까지 끌면 지정한 가중치가 바뀌며 학습 실행은 아닙니다. a = 1이면 F = 0.1, y = 2.1입니다. 들어오는 기울기 −0.1에 대해 지름길의 기여는 −0.1, 가지의 기여는 +0.01, 합은 −0.09입니다. 가지 가중치의 기울기는 −0.2입니다. 역전파가 미분을 계산하고 최적화 알고리즘이 가중치를 바꿉니다.

The depth bars are a separate local-derivative toy. Plain blocks are ReLU(−0.1x + 1.1); residual blocks are ReLU(x − 0.1x + 0.1). At x = 1 both stay at 1, with active ReLUs and final loss y²/2. After n blocks the signed input gradients are (−0.1)ⁿ and 0.9ⁿ. We display magnitudes normalized to 100: at n = 8, less than 1 versus about 43. These are different full mappings with independently chosen biases, not equally trained networks. Cancellation (branch slope −1) or an inactive post-add ReLU can block the signal. Larger gradients are not always better; zero residual preserves only nonnegative inputs through the final ReLU.

깊이 막대는 별도의 국소 미분 모형입니다. 직접 매핑 블록은 ReLU(−0.1x + 1.1), 잔차 블록은 ReLU(x − 0.1x + 0.1)입니다. x = 1에서 둘 다 1을 유지하고 ReLU가 활성화되며 마지막 손실은 y²/2입니다. n개 블록의 부호 있는 입력 기울기는 (−0.1)ⁿ과 0.9ⁿ입니다. 크기를 출발 100으로 표시하므로 n = 8에서 1 미만과 약 43이 됩니다. 편향을 각각 지정한 서로 다른 전체 함수이며, 같은 조건으로 학습한 신경망 비교가 아닙니다. 가지 기울기 −1의 상쇄 또는 비활성 ReLU는 신호를 막을 수 있습니다. 큰 기울기가 항상 좋은 것은 아니며, 수정분 0도 최종 ReLU 뒤에는 음이 아닌 입력만 그대로 보존합니다.
