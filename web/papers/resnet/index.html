What exactly are we watching?어떤 조건으로 만든 영상인가요?
y=ReLU(x+F(x))

An original 32×32 two-tone pattern with input values 0.25 and 0.75; the declared contrast target uses 0.05 and 0.95. A two-unit branch computes F(x) = a [0.8 ReLU(x) − 0.4 ReLU(1)], and the block outputs ReLU(x + F(x)). Its hidden weights are [1,0], biases [0,1], and output weights a[0.8,−0.4]. Dragging varies a from 0 to 1; it is a parameter sweep, not training. Change colors encode signed brightness (teal adds, orange subtracts), while images use gray. This illustrates §3.2, Eq. (1) with post-addition ReLU, not an ImageNet experiment, a trained ResNet or a performance comparison with a plain network. Zero F preserves nonnegative inputs; negative inputs are still clipped by the final ReLU.

직접 만든 32×32 두 밝기 무늬입니다. 입력은 0.25·0.75, 정한 대비 목표는 0.05·0.95입니다. 두 노드 경로가 F(x) = a [0.8 ReLU(x) − 0.4 ReLU(1)]을 계산하며, 출력은 ReLU(x + F(x))입니다. 은닉 가중치는 [1,0], 편향은 [0,1], 출력 가중치는 a[0.8,−0.4]입니다. 조작은 a를 0에서 1까지 바꾸는 것으로 학습 과정이 아닙니다. 변화량의 청록색은 밝기 추가, 주황색은 밝기 감소를 뜻하며 입력과 출력은 회색조입니다. 원문 §3.2 식 (1)과 덧셈 뒤 ReLU를 보여주는 예시이며 ImageNet 실험이나 학습한 ResNet, 일반 신경망과의 성능 비교가 아닙니다. F가 0이면 음이 아닌 입력을 유지하지만 음수 입력은 마지막 ReLU가 잘라냅니다.
