Privacy, access and reuse개인정보·접근성·재사용

The lessons require no account and include no project analytics or answer collection. The language preference is stored in your browser. GitHub Pages serves the files under GitHub's own service policies. Only survey aggregates are public; individual student records remain private.계정 없이 이용하며 프로젝트 자체 분석 추적이나 답변 수집 기능은 없습니다. 언어 선택은 브라우저에 저장합니다. 파일 제공에는 GitHub Pages의 서비스 정책이 적용됩니다. 설문은 집계만 공개하고 학생별 원본은 비공개로 둡니다.

Pause and seek the films; use their captions, text notes and keyboard sliders. English content remains readable without JavaScript; interactive calculations require it. JavaScript 없이 영어 설명을 읽을 수 있으며 상호작용 계산에는 JavaScript가 필요합니다. 원문 논문은 해당 출판 조건을 따릅니다. 자체 코드와 제작 자료는 MIT이며 별도 출처가 있는 입력 자료의 고지는 유지합니다.
